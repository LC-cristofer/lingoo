# Lingoo: Unit 1 complete (v2 as the child's experience) — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The child plays Unit 1 "Animais da floresta" from the start screen to the sticker in the album, entirely on the v2 trail (song, 3 lessons, story, challenge, chest), with existing saved progress preserved, and the Phase 1 flow removed.

**Architecture:** Reuse what exists: content JSON validated by zod, pure domain functions in `src/domain/trail/`, thin React screens built from the kit (`src/components/trail/kit/`). The lesson loop inside `StopPlayer` is extracted once and reused by the new song and story players. Progress gets a versioned local store (v3) that migrates v1/v2 without deleting them.

**Tech Stack:** Next.js 16.4.5 (App Router, `cacheComponents`), React 19.3, TypeScript, zod 4, Tailwind 4, Vitest 5 + Testing Library, Playwright 1.65.

**Spec:** `docs/superpowers/specs/2026-11-09-redesenho-trilha-design.md` (sections 5.1–5.6, 7, 8), with the decisions of 2026-11-16 below. Earlier plan: `docs/superpowers/plans/2026-11-10-redesenho-trilha.md` (Tasks 12, 13, 14 are replaced by this plan; Task 16 "memory training" is **out of scope** for this cycle).

## Decisions of 2026-11-16 (override earlier text where they differ)

- Audience is **6–10 years**. Pedagogical differentiation 6–7 / 8–10 is a **later** cycle; this cycle changes no exercise or content for it.
- Song and story players ship **before** the v2 trail is the child's entry point. No skipped stops, no "Em construção", no fake features.
- v1 is removed **only after** v2 e2e coverage exists and the progress migration ships. **No storage key is ever deleted** in this cycle.
- One star per completed stop. No performance scoring.
- Scope is Unit 1 only. No new exercise types, no extra gamification, no backend.
- Work only on branch `redesenho-trilha`. Never merge into `main`.
- **Approved with the plan:** the Memória tab is **hidden** (`BottomNav showMemory={false}`), never shown disabled; the legacy v1 fox sticker stays in a "Figurinhas especiais" album section with its line "A fox sticker!" generated by Chatterbox, and grants no v2 stop credit; `lingoo:progress:v1` and `lingoo:progress:v2` are preserved byte for byte, and a corrupt v3 is backed up before any rebuild. Execution: native, the nine tasks in order, one commit per task, independent review at the end.

## Global Constraints

- On-screen text is short and **always narrated**. Instructions `pt-BR`; words, target phrases and praise `en-US`, rendered with `lang="en"`.
- Feedback never says "wrong"; retry/hint sheet is orange `#FFA94D`, correct is green `#2F9E5B`; never red.
- Touch targets ≥ **64×64 px**; answer tiles ≥ **120×120 px**.
- Every screen uses the kit (`ForestScene`, `ChunkyButton`, `Bubble`, `WoodSign`, `StopButton`, `TopChips`, `BottomNav`, `FeedbackSheet`, `AnswerTile`); no screen defines its own colour or shadow; the main action is the sun-yellow button; no full-page cream/white background.
- Visual reference: `docs/arte/telas-aprovadas/*.png` and `tools/visual/mockups.tsx`.
- Form factors: phone portrait **390×844** and tablet landscape **1024×768** polished; phone landscape and tablet portrait must not clip controls or scroll horizontally.
- Audio only after the first touch (`narrator.unlock`). A failing audio file falls back to the browser voice for that segment; nothing ever gets stuck.
- **No new spoken lines** unless unavoidable; reuse `content/lines.json`. Any new line needs its MP3 generated with `tools/audio/generate.py` + `verify.py` (≈1 min per line on CPU) before the task is done.
- Preserve the pure domain functions (`session.ts`, `exercises.ts`, `progress.ts`, `schema.ts`, `content.ts`, `audio-id.ts`) and their tests: they may gain functions/fields, existing behaviour and tests stay green.
- Before writing a route or using a Next API, read the matching guide in `node_modules/next/dist/docs/` (AGENTS.md).
- Code and identifiers in English; commits in the repository's format with its attribution lines.
- Each task ends green: `npm test && npx tsc --noEmit && npm run lint` (+ `npm run e2e` where the task touches e2e).

## Review Focus

1. **Saved progress from an older build** (v1 key, v2 key, both, or a corrupted value). Nothing earned is lost; old keys stay byte-identical. Tested in Task 7.
2. **The song file fails or is slow** (404, decode error, autoplay refused). The karaoke continues line by line with narration; the child can always reach "Continuar". Tested in Task 3 (unit) and Task 3 e2e.
3. **Leaving mid-song or mid-story** (✕, browser back). Music and narration stop; no credit; the map is silent. Tested in Tasks 3 and 4.
4. **Fast double taps on "Avançar"/"Continuar"/stops** advance exactly once. Tested in Tasks 4 and 5.
5. **Phone landscape (844×390) and tablet portrait (768×1024).** No clipped controls, no horizontal page scroll on map, lesson, story, album. Tested in Task 9.
